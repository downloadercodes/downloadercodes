# Downloader Codes

Short codes for the **Downloader** app on Fire TV, Fire Stick, Android TV and Google TV.
Type a code instead of a long URL and install in seconds.

**Website:** [downloadercodes.com](https://downloadercodes.com)

## What you will find
- A searchable directory of Downloader codes, organised by category
- A [Code Checker](https://downloadercodes.com) to see if a code is still valid
- Step-by-step guides, for example [How to use Downloader codes](https://downloadercodes.com/blog/how-to-use-downloader-codes/)

## Open source list
The most popular codes are kept in this repository and are open to contributions:
[downloadercodes/list](https://github.com/downloadercodes/list)

- Only official sources (app stores or official developer sites)
- No APK files are hosted here
- Found a broken code? Open an issue. Want to add one? Open a Pull Request.

## Quick start
1. Install **Downloader** from the Amazon Appstore or Google Play
2. Open it and select the URL box
3. Enter a code from [downloadercodes.com](https://downloadercodes.com)
4. Wait for the download and select Install
